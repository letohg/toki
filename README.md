# Toki

A terminal time-tracking TUI built with **Rust** and **Ratatui**.

---

## The Philosophy

The goal of this project is to spark the joy of programming, which can easily feel lost in the era of generative AI and automated coding.

While its GUI counterpart, [TimeTracker](https://github.com/LetoHG/time-tracker), was built entirely by autonomous AI agents through prompting, **Toki is the exact opposite**.

I am building this application without letting AI write a single line of code. Instead, I use AI strictly as a mentor and peer - leveraging it for feedback, architectural guidance, and learning, while restricting it from generating project-related code.

## Key Features & Compatibility

* **Shared Ecosystem**: Fully compatible with the TimeTracker GUI.
* **Unified Data**: Uses the exact same database file and storage location, allowing you to switch seamlessly between the CLI and GUI.
* **Lightweight** & Fast: Built with Rust for optimal terminal performance.
